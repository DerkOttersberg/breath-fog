# Historical Minecraft 26.2 evidence

The files in this directory came from the original 26.2 Fabric MVP. They preserve its shader, multiplayer, build and performance history. They do not establish acceptance for another Minecraft version or loader.

The current branch's own report is [TESTING.txt](../TESTING.txt). Its recorded profiles, hashes, renderer and limitations identify the applicable acceptance evidence. Additional historical reports are in [docs/historical](../docs/historical).
