BREATH FOG 1.0.0 — MINECRAFT 26.3 / JAVA 25

Install the runtime JAR matching your loader in your profile's mods folder.
Fabric: Loader 0.19.5 + Fabric API 0.161.0+26.3.
Forge: 66.0.9. NeoForge: 26.3.0.48-beta. No extra runtime mod is required.
Do not install sources or QA helper JARs as gameplay mods.

Visit a cold biome, or run /breathfog preview for a 20-second preview.
Try first person and both third-person views using F5.
Open /breathfog config, optional Mod Menu (Fabric),
or Forge/NeoForge's Mods config button.

On the Appearance page, Pixelated Minecraft style is enabled by default. Change it and select Save.
Disable that option for soft vapor. Cancel discards changes; Reset defaults
changes your draft. Preview uses saved settings. Settings survive restarts
in config/breath_fog.json. New configs and Reset defaults use pixelated vapor. Existing explicit style choices are preserved.

Only the viewing client needs this mod. Servers and nearby players need
no installation. The mod changes no gameplay and sends no packets.
Dead, sleeping, spectating, invisible and submerged players do not emit.
Cold detection uses biome temperature below 0.5 or c:is_cold, including
indoors. Vanilla's Minimal particle setting reduces the effect.

If vapor is too subtle, raise Vapor intensity or First-person strength.
The central aiming area is intentionally attenuated. All required sprites
and the icon are bundled; no extra resource pack is needed.

Build with Java 25 using ./gradlew clean check build (gradlew.bat on Windows).
README.md lists installations, TESTING.txt records the exact acceptance
matrix and limits, and PORTING.md explains the multi-loader implementation.

Pixelated breath is the default in new configs and after Reset defaults.
Explicitly saved soft-style choices remain unchanged.
