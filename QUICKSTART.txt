BREATH FOG — MINECRAFT 1.21.1

Install the runtime JAR matching Minecraft 1.21.1 and your loader.
Use Java 21. Fabric requires Fabric API 0.116.17+1.21.1; Forge requires 52.1.16 or
a compatible later build in the same major line.
NeoForge requires 21.1.255 or a compatible 21.1 build.

Open /breathfog config, optional Mod Menu 11.0.5 on Fabric,
or the loader's Mods config button. Appearance > Pixelated Minecraft style
switches to 16x16 sprites. Select Save to apply; Cancel discards your draft.
/breathfog preview displays a 20-second preview in any biome.
Settings are in config/breath_fog.json. Only the viewer installs this mod.
Servers need no mod or loader. Cold biomes produce normal breath; sleeping,
death, invisibility, spectator mode and underwater suppress it.

Source: https://github.com/DerkOttersberg/breath-fog/tree/1.21.1
See TESTING.txt for exact packaged-client checks and limits. CC0-1.0.

Pixelated breath is the default in new configs and after Reset defaults.
Explicitly saved soft-style choices remain unchanged.
