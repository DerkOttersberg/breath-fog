BREATH FOG — MINECRAFT 1.20.1

Install the runtime JAR matching Minecraft 1.20.1 and your loader.
Use Java 17. Fabric requires Fabric API 0.92.12+1.20.1; Forge requires 47.4.26 or
a compatible later build in the same major line.

Open /breathfog config, optional Mod Menu 7.2.2 on Fabric,
or the loader's Mods config button. Appearance > Pixelated Minecraft style
switches to 16x16 sprites. Select Save to apply; Cancel discards your draft.
/breathfog preview displays a 20-second preview in any biome.
Settings are in config/breath_fog.json. Only the viewer installs this mod.
Servers need no mod or loader. Cold biomes produce normal breath; sleeping,
death, invisibility, spectator mode and underwater suppress it.
