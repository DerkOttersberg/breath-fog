FEATURES EXERCISED
Both styles, first person and both third-person cameras; sprinting/sneaking/riding;
actual visibility buttons, Save/Cancel, NaN rejection, draft preservation through
resize/pagination, native config factories and the real /breathfog config send path.
Settings captures at GUI scales 2 and 3 are inspected. Mod Menu's actual registered
factory is exercised in Fabric profiles where it is installed. Separate Fabric
profiles omit Mod Menu and still pass commands, settings and the full visual suite.
Resource reload reacquires sprites; a real filtering resource pack removes Breath
Fog sprites and suspends emission; removing that pack restores rendered breath.
A deterministic QA probe places an actual production BreathParticle against a real
glass block and verifies collision fading. With 48 synthetic nearby actors, the
controller selects the nearest 24 and stays below its 256-owned-particle cap.
Natural cold breath cycles without preview; measured controller-tick intervals agree
with idle cadence (unit tests validate exact 64–96 / 44–64 idle/sprint bounds).
Warm plains suppress normal breath and allow local preview. Disable/style change,
sleep/death/spectator/invisibility/submersion suppress or clean particles. Respawn
restores emission. Forge's forced-10-FPS scenario preserves simulation cadence.
Every standalone profile joins an entirely unmodded vanilla 1.21.1 loopback server
and renders breath in its snowy biome, then disconnects with zero owned particles.
This uses copied previously accepted QA EULA and offline development identities.
Combined profiles test the modded integrated world; companion mods may require
their loader on a remote server. No server installation is needed for Breath Fog.
