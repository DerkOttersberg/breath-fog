FEATURE CHECKS
Both saved styles render; first person and both third-person cameras work.
Actual settings buttons exercise pixel toggle, Cancel, Save, invalid NaN
rejection, pagination and draft-preserving GUI resizing; scales 2 and 3 are
captured. Combined profiles start a new client process with a saved pixel
config and verify it loaded before changing it for the test.
Local /breathfog config opens through the real client send path.
The mod cleans owned particles when disabled, on style change, disconnect,
and resource reload. The current harness waits for the reload future and
for Minecraft to resume before testing subsequent emission.

Actual in-game scenarios exercise sprinting, sneaking, riding a boat,
sleeping, underwater, invisibility, spectator mode, death and respawn.
Sleeping/death/spectator/invisible/submerged players stop emitting; respawn
restores breath. Warm plains suppress normal breath; saved-setting preview
renders there. Preview continues to respect visibility/suppression rules.
With 48 synthetic remote actors, the controller selects 24 nearest emitters
and stays below its 256-particle cap. This is a budget/motion check, not a
GPU benchmark or evidence of 48 actual multiplayer connections.

An entirely unmodded dedicated vanilla 26.3 server is launched on loopback
with copied, previously accepted QA EULA and offline development identities.
Every standalone loader profile joins it and emits breath in its snowy biome; server
installation of Breath Fog or loader libraries is unnecessary. This proves
that connection case, not authenticated LAN or a second actual guest client.
Disconnect leaves no owned particles. The owned server is stopped after QA.
The NeoForge companion suite rejects vanilla-server login because its other
mods require NeoForge payload support. Its combined acceptance uses a modded
integrated-server world; the independent Breath Fog NeoForge profile passes
vanilla login. That expected suite constraint is retained in the failed attempt.

LOG REVIEW AND FAILED ATTEMPTS
Offline placeholder identities produce user-properties/Realms authentication
diagnostics. WSL lacks the narrator flite library and an OpenAL device;
Minecraft disables those services. These messages are distinct from a mod
exception. Passing final profiles have no Breath Fog stack traces.

Earlier Forge runs exposed legacy tick/command events missing the new
in-world loop. Forge-only lifecycle and command mixins now bridge them;
the shared controller processes each game-time value once to avoid duplicate
ticks. Forge also hooks each simulation tick so low render FPS cannot slow
the breath clock; a forced 10 FPS run verifies controller/game-time cadence.
A missing Mixin minVersion declaration was corrected and retested.
QA bootstrap, reentrancy, reload timing and shared-lock failures are retained;
they do not become PASS markers. Failed profiles/logs are not deleted.
Quilt's Maven loader checksum is verified; its differing metadata API hash
is retained in installations/quilt-profile-2/loader-checksum.json.

LIMITS
No 26.3 hardware OpenGL/GPU performance benchmark, shader-pack matrix,
authenticated LAN, second actual guest, or exhaustive other-mod/resource-pack
matrix is claimed. Current tests verify standard lit/depth-tested particles;
they do not guarantee every shader pack's brightness or translucency ordering.
The 26.2 shader, multiplayer and hardware results remain historical in
docs/historical/TESTING-26.2.txt and the original evidence directory.
Server gameplay GameTests do not exercise this client-only visual feature;
actual isolated client/world scenarios provide the relevant runtime gate.
